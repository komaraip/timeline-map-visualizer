# Code of Conduct

We want this project to be a welcoming, safe, and constructive place to collaborate.

Contributors must communicate respectfully, accept useful feedback, avoid harassment and discrimination, and protect the privacy of other people. Do not post real location histories, addresses, coordinates, account identifiers, or other sensitive personal data in issues, discussions, fixtures, or pull requests.

Project maintainers may edit or remove contributions and temporarily or permanently restrict participation when behavior threatens community safety, privacy, or productive collaboration. Report conduct concerns privately to the maintainer contact published in the repository profile or security policy.
